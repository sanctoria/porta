# Porta

Porta is a free WordPress plugin that brands the login, registration and lost-password screens with your logo, colors and background. It includes a live preview, optional login-with-email, a show-password toggle, a honeypot, and local login-attempt limiting. No accounts or external services are required. Settings: Appearance → Porta.

## Requirements

- WordPress 6.4 or later
- PHP 7.4 or later
- Tested up to WordPress 7.1

## Installation

Porta is currently in review for [WordPress.org](https://wordpress.org/plugins/). Once it is listed, you can install it from Plugins → Add New. Until then, download the zip from [Releases](https://github.com/sanctoria/porta/releases) and upload it under Plugins → Add New → Upload Plugin.
