# Sanctoria Porta

Sanctoria Porta is a free WordPress plugin that brands the login, registration and lost-password screens with your logo, colors and background. It includes a live preview, optional login-with-email, a show-password toggle, a honeypot, and local login-attempt limiting. No accounts or external services are required. Settings: Appearance → Sanctoria Porta.

The plugin slug and folder are `sanctoria-porta` (version 1.0.1). This is a rename of Porta 1.0.0, after a WordPress.org review of the older name and slug.

## Requirements

- WordPress 6.4 or later
- PHP 7.4 or later
- Tested up to WordPress 7.1

## Installation

Sanctoria Porta is in review for the [WordPress.org plugin directory](https://wordpress.org/plugins/) under the slug `sanctoria-porta`. Until it is listed, download the zip from [Releases](https://github.com/sanctoria/porta/releases) and upload it under Plugins → Add New → Upload Plugin.

## Optional Pro add-on

An optional Pro add-on, [Sanctoria Porta Pro](https://sanctoria.com/plugins/porta/), is sold on the Sanctoria Porta product page. It adds:

- Ten ready-made login templates
- Styling for registration and lost-password screens
- Form position options, optional entrance animations, and a Media Library video background
- A user-initiated Google Fonts download, served only from this site
- Passkey sign-in (Windows Hello, Face ID, Touch ID), stored on this site
- A custom login URL, with emailed recovery and a wp-config.php bypass
- Role-based login and logout redirects
- Auto-logout after inactivity, a math captcha, a terms checkbox and custom fields on registration, a password strength meter on registration and reset forms, and a maintenance gate
- An optional local login activity log
- White-label for the WordPress admin (admin bar logo, footer text, and a dashboard widget)
- Import and export of design settings
- A login form shortcode and block
